# g.OS downloads

Installers for the g.OS desktop app. The source code is private.

**Mac:** [Download g.OS for Mac](https://github.com/allsoulsavenue/g.OS-releases/releases/latest/download/gos-mac.dmg)

The first time you open it, macOS may say it is from an unidentified developer. Right-click (or Control-click) g.OS in Applications and choose **Open**, or go to System Settings → Privacy & Security and click **Open Anyway**.
